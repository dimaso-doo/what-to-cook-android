# Recipe content licensing

The starter recipes marked as **Dimaso original recipe** are original project content.

Imported recipe text in `data/wikibooks_recipes.json` is adapted from the
[Wikibooks Cookbook](https://en.wikibooks.org/wiki/Cookbook:Table_of_Contents).
Each record contains a permanent source URL with the exact source revision and
credits **Wikibooks contributors**. The adapted text is distributed under the
[Creative Commons Attribution-ShareAlike 4.0 International license](https://creativecommons.org/licenses/by-sa/4.0/).

The import process changes formatting, normalizes ingredient names, and applies
deterministic validation for exact ingredient matching. Source and license details
remain attached to every imported recipe and are shown in the Android recipe view.
No Wikibooks images are copied or distributed by this project.
